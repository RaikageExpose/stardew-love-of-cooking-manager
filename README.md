## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Recipe Log** | Track which Love of Cooking recipes you have unlocked |
| **Ingredient Planner** | Calculate what to grow or gather for your cooking targets |
| **Cooking Calendar** | Plan which recipes to cook each season for max buffs |
| **Buff Optimizer** | Find recipes giving the best buffs for upcoming mine or farm days |
